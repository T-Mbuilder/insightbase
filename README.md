# Insightbase

AI knowledge base Q&A. Upload or paste documents, ask questions in any language, and get cited answers from the most relevant chunks.

- **Retrieval** — sentence/paragraph chunker + lexical/BM25-lite scoring with Chinese and English tokenization
- **LLM-ready** — when `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL` are set as server-side env vars, answers are generated by any OpenAI-compatible `/chat/completions` API
- **Demo mode** — without LLM env vars, a built-in retrieval-only engine returns cited excerpts so the app works stand-alone
- **Static + serverless** — vanilla HTML/CSS/JS frontend, one Vercel Node function at `/api/chat`

## Live demo

- Deployed: `https://insightbase-tau.vercel.app` (alias may change)
- Local dev: `vercel dev`

## Project structure

```
index.html        dark single-page UI (chat, document library, add-knowledge panel)
api/chat.mjs      Vercel serverless API: chunking, retrieval scoring, LLM call or demo answer
vercel.json       clean URL and API configuration
```

## How the API works

`POST /api/chat`

```json
{
  "query": "What is Skill Bridge?",
  "history": [{ "role": "user", "content": "..." }],
  "docs": [{ "title": "Skill Bridge", "text": "..." }]
}
```

Response:

```json
{
  "ok": true,
  "mode": "demo | llm",
  "answer": "...",
  "citations": [{ "title": "Skill Bridge", "score": 0.99 }]
}
```

## Security & privacy

This repository contains no secrets and no personal data. API keys are injected as environment variables at deployment time from Vercel project settings; they are never committed or exposed in the client bundle.
